bezorg API

The machine-readable contract is /openapi.json. The listener is off unless --web-listen is set. Reads need the bearer token unless public read is enabled. Writes always need it.

bezorg to onderzeeer

Create a download with external_id. After every file has its final name, bezorg writes one <local>.bezorg-done.json manifest and renames it into place last. Point an onderzeeer watch at the directory that contains that manifest, ignore *.bezorg-partial, and read external_id from the manifest. Follow GET /api/v1/events or a webhook instead of polling jobs. download.succeeded includes the manifest path.

Webhook deliveries send X-bezorg-Event, X-bezorg-Delivery, and X-bezorg-Signature: t=<unix>,v1=<hmac>. The signed string is the unix time, a period, and the raw body.
