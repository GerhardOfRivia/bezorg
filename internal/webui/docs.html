bezorg API

The machine-readable contract is /openapi.json. The listener is off unless --web-listen is set. Reads need the bearer token unless public read is enabled. Writes always need it.

bezorg to onderzeeer

Create a download with external_id. Bezorg writes <file>.bezorg-id and renames it into place before renaming the .bezorg-partial data file. Point destination at an onderzeeer watch, exclude both suffixes, and read the sidecar from SetFileExternalID. Follow GET /api/v1/events or a webhook instead of polling jobs. download.succeeded is recorded after the atomic rename.

Webhook deliveries send X-bezorg-Event, X-bezorg-Delivery, and X-bezorg-Signature: t=<unix>,v1=<hmac>. The signed string is the unix time, a period, and the raw body.
